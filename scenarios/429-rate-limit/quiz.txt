Q: Where were the 429 responses coming from?
A) WordPress core's REST API
B) The hosting platform's nginx rate limit on admin-ajax.php
C) The client's ISP
ANSWER: B

Q: Why did the "Connection lost" message appear while editing?
A) Heartbeat (which also uses admin-ajax.php) got rate-limited along with the plugin's polling
B) The database dropped the connection
C) The session cookie expired
ANSWER: A

Q: The client asked you to remove the rate limit. Why is that the wrong fix?
A) It isn't; it's the fastest fix
B) It moves the cost onto every site on the server and hides a plugin that hits PHP every second per open tab
