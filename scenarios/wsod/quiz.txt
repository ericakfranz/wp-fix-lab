Q: Why was the page completely blank instead of showing an error?
A) The theme files were deleted
B) Errors weren't displayed on screen and WordPress's "critical error" handler was turned off
C) The database was unreachable
ANSWER: B

Q: What was the root cause?
A) A plugin called a function that only existed in a plugin the client had deleted
B) PHP ran out of memory
C) A corrupted .htaccess file
ANSWER: A

Q: Running `./lab wp plugin deactivate simple-share-counts` fails with the same fatal error. Why, and what gets around it?
A) WP-CLI needs root; use sudo
B) WP-CLI loads plugins too; add --skip-plugins
C) The plugin is network-activated; add --network
ANSWER: B
